# Amie Salon

Website project for Amie Salon.

## Status

`index.html` is the built site — a single self-contained HTML/CSS/JS file
built to be pasted into a GoHighLevel (GHL) Custom HTML element. See
[GHL-INSTRUCTIONS.md](./GHL-INSTRUCTIONS.md) for how to paste it in and how
image hosting works.

Asset structure lives under `/public` — see [ASSETS.md](./ASSETS.md) for
exactly where to upload each website asset (logo, images, videos, icons,
fonts), and which ones are still missing.
